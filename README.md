# Reducing False Positives in Heuristic DNS Tunneling Detection: A Structural Analysis of Legitimate High-Entropy DNS Names

**Author:** MSc. Medardo Jairo Suntaxi Cocanguilla, C|EH  
**Version:** 1.0 – October 2026

Independent technical white paper on why heuristic DNS tunneling detectors
misclassify DKIM, Active Directory (`_msdcs`) and reverse-mapping (PTR) queries,
and how to mitigate those false positives without weakening detection.
